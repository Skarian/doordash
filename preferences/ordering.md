# Ordering Preferences

## Bottled water

- Do not select mini or 8 fl oz bottled water.
- Default to standard-size bottles: approximately 16.9 fl oz / 500 mL each.
- When the user requests a bottle count, prioritize both the requested count
  and standard-size bottles.
- If only smaller bottles are available, explain the available size and ask
  before substituting them.
